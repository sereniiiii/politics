# 政治知识库 · 高中思想政治考点

纯静态站点，无后端。七本书、58 课、222 条考点卡；三栏阅读（章节树 / 卡片列表 / 详情），另有「主体—职权矩阵」与「易混对照」两种视图；自带笔记、掌握状态、复盘记录与一键备份，可离线使用。

线上地址：<https://sereniiiii.github.io/politics/>

## 打开方式

**方式一：本地起服务（推荐，离线缓存可用）**

```bash
cd politics
python3 -m http.server 8788
# 浏览器打开 http://127.0.0.1:8788/
```

**方式二：直接双击 `index.html`**

页面可正常浏览、搜索、记笔记；Service Worker 只在 `http(s)` 下注册，`file://` 下没有离线缓存。

## 结构

```
politics/
├── index.html              主站（三栏 + 移动端折叠）
├── detail.html             独立详情页（?id=xxx，可单独分享）
├── sw.js                   离线缓存（zz-static-v7）
├── assets/
│   ├── css/site.css        视觉与布局（明暗双主题，无第三方依赖）
│   └── js/
│       ├── store.js        用户数据、快照、导入导出（localStorage）
│       ├── render.js       卡片 / 详情 / 徽标的唯一渲染源
│       ├── app.js          主站交互
│       └── detail.js       独立详情页
├── data/
│   ├── meta.json           七本书 / 单元 / 58 课的目录结构
│   ├── b1..b4.json         必修 1–4 考点
│   ├── x1..x3.json         选择性必修 1–3 考点
│   ├── matrix.json         主体—职权矩阵：10 个主体 × 5 个维度
│   ├── pairs.json          易混对照：8 组必分清的搭配
│   ├── content.js          合并产物（window.ZZ，供页面直接读取）
│   └── views.js            视图合并产物（window.ZZViews，由脚本生成）
└── tools/build_content.py  重新生成 content.js / views.js 并做结构校验
```

改内容只改 `data/*.json`（或 `meta.json`），然后：

```bash
python3 tools/build_content.py
```

脚本会校验：字段齐全、id 不重复、课次存在、难度/类型合法、摘要长度、每课至少一条；并校验矩阵每个主体五个维度都有值、对照每组两个定义与至少两条区别要点。不通过会列出具体条目并终止。

## 三种视图

顶部中间栏有三个切换：**考点卡 / 主体矩阵 / 易混对照**。左栏随之变成章节树、维度索引或对照索引，右栏同步显示主体详情或对照详情。

- **考点卡**：原有阅读方式，按书 → 单元 → 课定位，222 条考点逐条读。
- **主体矩阵**：10 个主体（党、人大、政府、政协、监委、法院、检察院、公民、主权国家、联合国）× 5 个维度（性质与地位、产生与组成、核心职权、监督与关系、最易错）。点左侧任一维度，所有卡片只显示这一行，竖着读即可看清同一维度下各主体的差别——政治选择题最常失分在“主体错位”，这张矩阵就是为此准备的。
- **易混对照**：8 组最容易混的搭配（国体/政体、人大/政协、权力机关/行政机关、根本/基本政治制度、民族区域自治/特别行政区、主权/人权、公民/人民、依法执政/依法行政），每组给两个定义、区别要点和陷阱句。

视图可深链：`?view=matrix&dim=power&s=court`、`?view=pairs&p=minzu-tebie`；`J` / `K` 在矩阵与对照里同样可用。

数据都在 `data/matrix.json` 与 `data/pairs.json`，改完跑 `python3 tools/build_content.py` 生成 `data/views.js` 即可，不用碰页面代码。

## 内容边界

- 依据统编版高中思想政治教材目录组织：必修 1–4、选择性必修 1–3，共 58 课。
- 每条是**考点归纳**（结论、要点、易错、考法、关键词），不摘录教材原文，不标教材页码，不做书源跳转。
- 没有把握的内容不虚构：宁可用更概括的表述，也不编造数据、原文或图片。
- 用户提供的《（超详）高中政治知识点归纳汇总.doc》属大纲版（经济常识 / 哲学常识 / 政治常识），与现行统编版结构不一致，仅用于哲学部分表述的交叉核对，未作为站点骨架。

## 数据与备份

内容（`data/`）与用户数据严格分离。用户数据全部在浏览器 `localStorage`：

| Key | 内容 |
| --- | --- |
| `zz.user.v1` | 笔记、掌握状态、复盘日期、自定义考点 |
| `zz.snapshots.v1` | 最近 6 份快照（导入 / 恢复 / 清空前、每日首次打开自动） |
| `zz.theme` | 明暗主题偏好 |

备份面板（顶栏「备份」）提供：

- **JSON 全量备份**：笔记、状态、复盘、自定义条目、配置
- **CSV 笔记表**：Excel 可直接打开，含状态、标记日期、复盘次数、最近复盘
- **Markdown 汇总**：按书/课分组，含要点、易错、考法与个人笔记
- **导入**：先校验 schema、状态值、自定义条目结构；通过后显示计数预览，可选「合并」（按更新时间取新、复盘日期取并集）或「覆盖」；两种方式都会先自动快照
- **快照回滚**：任一快照可一键恢复，恢复前再存一份当前状态

## 交互

- 三栏常驻：左章节树（书 → 单元 → 课）、中卡片流、右详情；≤980px 折叠为单列，底部「目录 / 列表 / 详情」切换。
- 视图切换：中间栏顶部三枚按钮；切到矩阵/对照时左栏自动换成维度或对照索引，移动端从底部「目录」进入索引、点卡片进「详情」抽屉。
- 卡片高度随内容自适应，不做固定高度与虚拟滚动，从根上避免截字。
- 搜索覆盖标题、摘要、要点、易错、考法、关键词、书名课名与**笔记正文**。
- 键盘：`/` 聚焦搜索、`J` / `K` 上下切换（矩阵与对照里切换主体/搭配）、`Enter` 在卡片视图打开独立详情页、`Esc` 关闭弹窗 / 清空搜索。
- 状态四色：已掌握（松绿）、待复盘（赭石）、今日已复盘（青蓝）、未标记（灰）。
- 切换分类/筛选/主题时保留滚动位置与选中态，不闪白、不跳动。

## 部署

托管在 GitHub Pages（仓库 `sereniiiii/politics`，`main` 分支根目录）。更新：

```bash
git add -A && git commit -m "update content" && git push
```

若改了 `site.css` / `assets/js/*` / `data/content.js` / `data/views.js`，记得同步把 `index.html`、`detail.html` 里的 `?v=` 与 `sw.js` 里的 `CACHE` 版本号 +1（当前 `20261124h` / `zz-static-v7`），否则老访客会命中旧缓存。
